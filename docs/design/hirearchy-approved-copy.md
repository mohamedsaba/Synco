## 4. Strictly Forbidden Copy & Claims

Implementation agents must **NEVER** use the following terms or concepts anywhere in copy, headings, alt text, or code comments:

### Forbidden Evaluative Scoring & Fit Labels

- ❌ `Strong fit` / `Good fit` / `Poor fit` / `Role fit`
- ❌ `Best candidate` / `Top candidate` / `High performer`
- ❌ `Recommended for hire` / `Not recommended`
- ❌ `Confidence score` / `Candidate score` / `Match %`
- ❌ `Hire` / `No-hire`
- ❌ `Candidate quality` / `Candidate ranking` / `Leaderboard`
- ❌ `AI insight` / `AI assessment` / `Automated evaluation`
- ❌ `Personality diagnosis` / `Culture fit` / `Behavioral index`

### Forbidden Unsupported Velocity & Metric Claims

- ❌ `70% faster screening` (or any percentage velocity claim)
- ❌ `Higher quality hires` (or any claim of superior hiring outcomes)
- ❌ `Bias reduced by X%` (or any unproven algorithmic fairness claim)
- ❌ `Improved accuracy` / `Predictive hiring`
- ❌ `Cut interview time in half` / `Automate your hiring funnel`
- ❌ `100% observable reality` (overclaims capture limits; real telemetry has boundaries)
